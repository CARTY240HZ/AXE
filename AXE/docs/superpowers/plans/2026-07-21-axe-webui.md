# AXE WebUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reemplazar la capa de presentación WPF de AXE por una UI WebView2 (HTML/CSS/JS) que supere a hone.gg / PulseHardware / Delta / Atlas en experiencia, sin tocar el motor (regiones 1–45) ni perder la honestidad (medible, reversible, con fuentes).

**Architecture:** El WPF se reduce a una carcasa fina (`47-webhost.ps1`) que abre una ventana y aloja **un** control WebView2 a pantalla completa. El frontend vive en `AXE/webui/`, servido local vía `SetVirtualHostNameToFolderMapping` (`https://axe.local/` → carpeta, solo-lectura). Un puente RPC (`48-webbridge.ps1`) despacha mensajes JS→PS contra una **lista blanca cerrada** de funciones del motor y empuja telemetría PS→JS por `DispatcherTimer`. Un solo proceso, sin servidor localhost, sin puerto abierto.

**Tech Stack:** PowerShell 5.1/7.x, WPF (host), WebView2 (SDK `Microsoft.Web.WebView2.*` + Evergreen runtime), HTML/CSS/JS vanilla (sin framework, sin CDN — CSP local), Pester, PSScriptAnalyzer, GitHub Actions.

## Global Constraints

Copiadas verbatim del spec `2026-07-21-axe-webui-design.md` y de las reglas del repo. Cada tarea las hereda.

- **Motor congelado:** ninguna edición en `src/00`…`src/45`. El catálogo (`$script:CAT`) es la única fuente de verdad. Si una pantalla necesita un dato que el motor no expone, se expone con una función **nueva** en un módulo nuevo, nunca modificando el motor.
- **Admin solo en el arranque GUI:** los módulos NO llevan `#Requires -RunAsAdministrator` (rompe el build por dot-source/concatenación).
- **Registro solo por primitivas** (`Set-RD`/`Set-RS`/`Del-RV`/`Set-SvcStart`); nunca `Set-ItemProperty` directo. La UI **no** toca el registro: llama a funciones del motor que ya lo hacen.
- **El puente nunca confía en el payload.** Lista blanca cerrada por defecto: `cmd` desconocido → rechazo. Nunca `Invoke-Expression`/eval del payload. Args validados por comando antes de tocar el motor.
- **Estética (regla dura, decidida con el usuario):** minimalista, **no genérico, no muy colorido**, movimiento y transiciones fluidas. Instrumento de medida, no UI gamer. Saturación reservada a riesgo (tier) y salud. Ámbar `#E0A32E` es la única luz de marca. `prefers-reduced-motion` honrado. Sin RGB, sin glow de sobra.
- **Tokens de color (exactos):** `--bg:#0E1013; --surface:#16191F; --surface-2:#1E232B; --line:#2A303B; --fg:#E6EAF0; --muted:#7E8798; --accent:#E0A32E; --green:#5FAF8D; --amber:#E0A32E; --red:#D9605A`.
- **Tipografía:** Segoe UI Variable (cara real de Windows) para UI; monospace tabular para toda lectura numérica (score, µs, %).
- **CSP local:** todo asset (CSS/JS/fuentes/SVG) es local en `AXE/webui/`. Cero peticiones a hosts externos. Cero CDN.
- **Verificar antes de "hecho":** `Invoke-ScriptAnalyzer -Severity Error` limpio + `build.ps1` con `RESULTADO: OK (0 fallos)` en `-SelfTest`. Full Pester para el puente llega en la Fase 9.
- **Migración detrás de flag:** hasta el cutover (Fase 8), la UI web solo arranca con `AXE_WEBUI=1`. Sin el flag, la GUI WPF actual sigue siendo el default → el gate CI/harness sigue verde durante toda la construcción.

```powershell
# REGION 13 - WEBVIEW2 HOST (carcasa) - DETECCION
# =====================================================

# Detecta el runtime Evergreen y los DLL del SDK. NO crea UI todavia.

function Get-AXEWebView2Runtime {
    # El runtime Evergreen registra su version aqui. Presente por defecto en Win11;
    # en Win10 puede faltar => Available=$false y la carcasa muestra un mensaje con enlace.
    $paths = @(
        'HKLM:\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}',
        'HKLM:\SOFTWARE\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}'
    )
    foreach($p in $paths){
        try {
            $v = (Get-ItemProperty -Path $p -Name pv -ErrorAction Stop).pv
            if($v -and $v -ne '0.0.0.0'){ return [pscustomobject]@{ Available=$true; Version=$v; Reason='' } }
        } catch {}
    }
    return [pscustomobject]@{ Available=$false; Version=$null; Reason='Runtime WebView2 Evergreen no encontrado. Instalalo desde https://developer.microsoft.com/microsoft-edge/webview2/' }
}
```

```powershell
function Show-AXEWebHost {
    # Guard STA (WPF lo exige; el .bat pasa -STA, esto cubre run directo)
    if($env:AXE_WEBUI_TEST -ne '1' -and [System.Threading.Thread]::CurrentThread.GetApartmentState() -ne 'STA'){
        Write-Host 'WebView2/WPF requiere STA. Relanza via AXE.bat.'; return
    }
    Add-Type -AssemblyName PresentationFramework
    Add-Type -AssemblyName PresentationCore
    Add-Type -AssemblyName WindowsBase

    $sdk = Get-AXEWebView2SdkPath
    if(-not $sdk){ [System.Windows.MessageBox]::Show('Faltan los DLL de WebView2 (AXE/webview2/). Reinstala AXE.','AXE','OK','Error') | Out-Null; return }
    # Orden de carga importa: Core antes que Wpf. El nativo WebView2Loader.dll lo resuelve el runtime
    # desde el subdir runtimes\win-x64\native.
    Add-Type -Path (Join-Path $sdk 'Microsoft.Web.WebView2.Core.dll')
    Add-Type -Path (Join-Path $sdk 'Microsoft.Web.WebView2.Wpf.dll')

    $rt = Get-AXEWebView2Runtime
    $win = New-Object System.Windows.Window
    $win.Title='AXE'; $win.Width=1200; $win.Height=840; $win.MinWidth=1040; $win.MinHeight=720
    $win.WindowStartupLocation='CenterScreen'
    $win.Background=[System.Windows.Media.BrushConverter]::new().ConvertFrom('#0E1013')
    $script:WebWin = $win

    if(-not $rt.Available){
        # Runtime ausente: no pantalla en blanco. Mensaje claro con enlace (riesgo #4 del spec).
        $tb = New-Object System.Windows.Controls.TextBlock
        $tb.Text = $rt.Reason; $tb.TextWrapping='Wrap'; $tb.Margin='40'
        $tb.Foreground=[System.Windows.Media.BrushConverter]::new().ConvertFrom('#E6EAF0')
        $win.Content=$tb; [void]$win.ShowDialog(); return
    }

    $web = New-Object Microsoft.Web.WebView2.Wpf.WebView2
    $script:Web = $web
    $win.Content = $web

    # user data folder fuera de Archivos de programa (evita fallo de permisos)
    $udf = Join-Path $env:LOCALAPPDATA 'AXE\WebView2'
    if(-not (Test-Path $udf)){ New-Item -ItemType Directory -Path $udf -Force | Out-Null }

    # Init asincrono: suscribir el evento ANTES de EnsureCoreWebView2Async. Cuando complete,
    # mapear el host virtual y navegar. Evita el .GetAwaiter().GetResult() que puede deadlockear en STA.
    $web.Add_CoreWebView2InitializationCompleted({
        param($s,$e)
        if(-not $e.IsSuccess){ Write-AXELog "WebView2 init fallo: $($e.InitializationException)" 'ERR'; return }
        $core = $s.CoreWebView2
        # host virtual -> carpeta local, solo lectura (Deny cross-origin)
        $core.SetVirtualHostNameToFolderMapping('axe.local', $script:WebUIDir, 'Deny')
        if($env:AXE_WEBUI_DEBUG -ne '1'){
            $core.Settings.AreDefaultContextMenusEnabled = $false
            $core.Settings.AreDevToolsEnabled = $false
        }
        $core.Settings.IsStatusBarEnabled = $false
        Register-AXEBridge $core   # Fase 2: stub hasta que exista
        $s.Source = [uri]'https://axe.local/index.html'
    })

    $env = [Microsoft.Web.WebView2.Core.CoreWebView2Environment]::CreateAsync($null,$udf,$null)
    $web.EnsureCoreWebView2Async($env.GetAwaiter().GetResult()) | Out-Null

    [void]$win.ShowDialog()
}
```

```powershell
# =====================================================
# REGION 14 - PUENTE RPC (JS <-> PS). SUPERFICIE DE ATAQUE.
# =====================================================
# Regla dura: lista blanca cerrada. cmd fuera de la lista => rechazo. Nunca eval del payload.
# Cargar este modulo SOLO define funciones y el mapa; nada se ejecuta hasta Register-AXEBridge.

# Mapa cerrado: cmd -> scriptblock($args) que devuelve el 'data' (o lanza).
# Cada entrada mapea a una funcion YA EXISTENTE del motor (1-45). No se anade logica de negocio aqui.
$script:AXEBridgeMap = @{
    'hw.get' = { param($a)
        if(-not $script:HW){ $script:HW = Get-AXEHardware }
        $script:HW
    }
}

function Invoke-AXEBridgeCmd {
    param([string]$cmd,[hashtable]$args)
    $fn = $script:AXEBridgeMap[$cmd]
    if(-not $fn){ return [pscustomobject]@{ ok=$false; data=$null; err="cmd desconocido: $cmd" } }
    try {
        $data = & $fn $args
        return [pscustomobject]@{ ok=$true; data=$data; err='' }
    } catch {
        Write-AXELog "Puente: $cmd lanzo: $($_.Exception.Message)" 'ERR'
        return [pscustomobject]@{ ok=$false; data=$null; err=$_.Exception.Message }
    }
}

function Register-AXEBridge($core){
    # JS -> PS: cada mensaje es {id, cmd, args}. Se responde por ExecuteScriptAsync(__axeReply).
    $core.add_WebMessageReceived({
        param($s,$e)
        $reqId = -1
        try {
            $msg = $e.WebMessageAsJson | ConvertFrom-Json
            $reqId = [int]$msg.id
            $argsHt = @{}
            if($msg.args){ $msg.args.PSObject.Properties | ForEach-Object { $argsHt[$_.Name] = $_.Value } }
            $res = Invoke-AXEBridgeCmd $msg.cmd $argsHt
        } catch {
            $res = [pscustomobject]@{ ok=$false; data=$null; err="payload invalido: $($_.Exception.Message)" }
        }
        $json = ($res | ConvertTo-Json -Depth 8 -Compress)
        # __axeReply(id, jsonString): el JSON va como argumento string (JSON.parse en JS).
        # ConvertTo-Json del string lo envuelve en comillas escapadas => sin inyeccion en ExecuteScriptAsync.
        $js = 'window.__axeReply(' + $reqId + ', ' + ($json | ConvertTo-Json) + ')'
        [void]$s.ExecuteScriptAsync($js)
    })
}
```

```js
// Cliente del puente RPC. JS -> PS por postMessage; PS -> JS por __axeReply / eventos.
(function () {
  const pending = new Map();
  let seq = 1;
  const listeners = new Map(); // evt -> Set<fn>

  window.__axeReply = function (id, json) {
    const p = pending.get(id);
    if (!p) return;
    pending.delete(id);
    let res;
    try { res = JSON.parse(json); } catch (e) { p.reject(new Error('respuesta ilegible')); return; }
    if (res.ok) p.resolve(res.data); else p.reject(new Error(res.err || 'error'));
  };

  function call(cmd, args) {
    return new Promise((resolve, reject) => {
      const id = seq++;
      pending.set(id, { resolve, reject });
      const bridge = window.chrome && window.chrome.webview;
      if (!bridge) { reject(new Error('puente no disponible (¿fuera de WebView2?)')); return; }
      bridge.postMessage(JSON.stringify({ id, cmd, args: args || {} }));
      setTimeout(() => { if (pending.has(id)) { pending.delete(id); reject(new Error('timeout: ' + cmd)); } }, 15000);
    });
  }

  function on(evt, fn) {
    if (!listeners.has(evt)) listeners.set(evt, new Set());
    listeners.get(evt).add(fn);
    return () => listeners.get(evt).delete(fn);
  }

  // PS -> JS telemetria: PostWebMessageAsJson llega por este evento (Fase 3).
  const bridge = window.chrome && window.chrome.webview;
  if (bridge) {
    bridge.addEventListener('message', (ev) => {
      const m = ev.data;
      if (m && m.evt && listeners.has(m.evt)) listeners.get(m.evt).forEach((fn) => fn(m.data));
    });
  }

  window.AXE = { call, on };
})();
```

```powershell
        param($buf)
        while($true){
            try {
                $j = [AXE.Native]::SampleJitter(250)   # {n,mean,max,p999,stalls}
                $buf.jitterMeanMs = [math]::Round($j[1],3)
                $buf.jitterP999Ms = [math]::Round($j[3],3)
                $buf.dpcProxyUs   = [math]::Round($j[3]*1000)   # proxy: p99.9 en us
                $os = Get-CimInstance Win32_OperatingSystem
                $buf.ramPct = [math]::Round(100*(1-($os.FreePhysicalMemory/$os.TotalVisibleMemorySize)))
                $cpu = (Get-CimInstance Win32_Processor | Measure-Object -Property LoadPercentage -Average).Average
                $buf.cpuPct = [int]$cpu
            } catch {}
            Start-Sleep -Milliseconds 250
        }
    }).AddArgument($script:TelemBuf)
    $script:TelemHandle = $ps.BeginInvoke()
    $script:TelemPS = $ps; $script:TelemRS = $rs
```
